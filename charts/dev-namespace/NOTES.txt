Provisioned namespace {{ include "dev-namespace.name" . }} for the herdr dev environments:

  - ServiceAccount deploy + ns-scoped Role/RoleBinding (the dev
    token manages Pens and, since 0.7.2, its own credential Secrets
    only: pod, Service and PVC creation is the operator's)
  - Secret deploy-token (explicit SA token; the token controller populates
    data.token asynchronously. Poll for it before reading)
  - Secret herdr-dev-{{ include "dev-namespace.name" . }} (authorized_keys for the env sshd)

Next steps (admin, see README.md):

  1. Read the token:
     kubectl -n {{ include "dev-namespace.name" . }} get secret deploy-token \
       -o jsonpath='{.data.token}' | base64 -d
  2. Create the ConfigMap herdr-dev-{{ include "dev-namespace.name" . }} with the dev image
     tag, the rendered agent config, and the developer's LLM-proxy key
     (cluster-tooling-specific, not part of this chart).
  3. Generate the developer's CLI config with `pipen config --out
     .herdr-<dev>.yaml --api-base ... --namespace ... --dev-user ...
     --token ...` and hand the file to the developer.
