pipen-operator installed (image {{ .Values.image }}) in namespace pipen.

Notes:
- This release is installed exactly once per cluster. Its cluster-scoped
  objects (ClusterRole, ClusterRoleBinding) and the CRD belong to a single
  release; a second release would conflict.
- The CRD is a release-managed resource (`templates/crd.yaml`): Helm
  installs it on Helm 3 and Helm 4 alike, and `helm upgrade` keeps it in
  sync. While v1alpha1 is frozen the rendered manifest never changes, so
  upgrades are no-ops. Do not remove the CRD from the chart: Helm would
  delete it.
- Give a developer a namespace with:
    helm install <dev> charts/dev-namespace --set dev=<dev> ...
  which grants the operator per-namespace write RBAC and a reduced Role to
  the developer's token.
